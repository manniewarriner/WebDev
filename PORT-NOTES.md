# Baseline port into orchdesk/merged

Source: `baseline-20261017` (`6a82dc7`). Destination architecture: `src/OrchDesk.Core` and `src/OrchDesk.App`, retaining Managed Auto, workspace permissions, provider rotation, OpenCode 2.0, accounts, overnight checkpoints and the existing agent panel.

## Tests and validation

`tests/OrchDesk.Tests/Baseline` contains the directly portable Automation, Efficiency, Meshy, Research and Markdown contracts, extracted supervisor persistence/pause/reset/cancel contracts, and additional cross-service integration tests. Architecture-specific assertions against the removed `IChatProvider`/`ToolExecutor`/legacy Orchestrator API were adapted into PromptContext, RunBudget, permissions, ManagedTeam and existing provider/agent tests rather than preserving a second implementation just to satisfy old test signatures. The baseline test that wrote a skill into the real user's home folder was replaced with synthetic temporary/reference data.

`BaselineCompatTests` covers sanitized config round-trip, providers, backup, Telegram preservation and folder permission/undo behavior. `LegacyChatImportTests` covers all model labels, non-destructive import, idempotence and deletion persistence. `PortedTeamTests` covers architect handoff, Opus review and shared model-call limits. Existing branch tests are retained.

The DPAPI round-trip test remains a real CurrentUser test using a temporary directory. It explicitly skips when a synthetic three-byte DPAPI probe fails because this process cannot access a usable Windows user profile. Production encryption was not weakened or replaced to make the sandbox pass.
