# Agent guide: The Lincoln Window Cleaner website

Read this first, then `memory/progress.md`, before changing anything.

## Project
- Static site for The Lincoln Window Cleaner (lincolnwindowcleaner.com): HTML, CSS and vanilla JS. No build framework.
- Working branch: `claude/elegant-sagan-x9oy5h`. Commit and push after every change. Never open a PR unless the user asks.

## How the site is built
- `index.html` is generated. Edit `parts/*.html`, then run `python3 tools/assemble.py`.
- Styles: `css/base.css`, `css/materials.css`, `css/sections/*.css`. Scripts: `js/main.js`, `js/sections/*.js` (GSAP, ScrollTrigger, Lenis and SplitType come from CDNs).
- Reviews: edit the list, then run `python3 tools/build_reviews.py`.
- Hero cathedral: generated by `tools/cath.py`.
  - Run `python3 -I tools/cath.py 0.86 738 -20 > cath.svgfrag`.
  - In `parts/hero.html`, replace everything from the line containing `LINCOLN CATHEDRAL` up to the line before `<!-- The hill` with that fragment.
  - Layers: LIT, SHD, DEEP and MID are the stone faces; TOP and TOPL are the door, drawn last.
- The castle (including the Lincolnshire flag) is hand-written SVG in `parts/hero.html`.

## Downloads
- `python3 tools/bundle.py` writes `LincolnWC-preview.html`, a single self-contained file: CSS is inlined, and JS and images are embedded as data URIs.
- Zip: `zip -qr LincolnWC-Site.zip index.html reviews.html privacy-policy.html css js assets`
- The Claude artifact preview is at https://claude.ai/artifact/S7q3tcq2DFcJVSvAQysQiV. Republish `LincolnWC-preview.html` to that URL.

## Before every push
- Run `assemble.py`, then `node --check` on every JS file.
- Screenshot the change at 1440px and 390px, and look at it.
- Copy the screenshots of whatever changed into `screenshots/`.

## Working with the user
- Give short summaries, with screenshots of what changed.
- The user wants realistic, solid architecture in the hero: no line-drawing look, no stroke outlines (it uses drop-shadows), and symmetric details.
- Design-review items in `docs/review-2026-10-08.md` are suggestions only. Build them only once the user approves.
- Photo hosts are blocked from the build environment, so the user supplies photos.
